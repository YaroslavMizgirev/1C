# Библиотека 1С

234 метода для платформы 1С:Предприятие 8.3.27 и 8.5.

## Руководства

- [Правила разработки и внесения изменений в информационные базы 1С](guides/DevelopersStandards.md)
- [Установка сервера хранилища конфигураций 1С для Astra Linux, Debian и Ubuntu](guides/ConfigurationStorageService.md)

## Общие модули

### [мямXLSX](docs/мямXLSX.md)

Создание книг и листов Excel, запись значений в ячейки и сборка файла XLSX. В модуль также входят средства работы с отдельными частями книги.

### [мямБулевоКлиентСервер](docs/мямБулевоКлиентСервер.md)

Проверяет тип значения и преобразует значение в булево.

### [мямДатаКлиентСервер](docs/мямДатаКлиентСервер.md)

Проверяет тип и заполненность даты, очищает дату и преобразует входное значение.

### [мямЖурналРегистрацииКлиентСервер](docs/мямЖурналРегистрацииКлиентСервер.md)

Возвращает уровни событий журнала регистрации для ошибок, предупреждений, информации и примечаний.

### [мямКомандыФормыСервер](docs/мямКомандыФормыСервер.md)

Добавляет и удаляет команды управляемой формы, задаёт их свойства.

### [мямМассивКлиентСервер](docs/мямМассивКлиентСервер.md)

Создаёт и дополняет массивы, ищет значения и формирует массивы типов для объектов метаданных.

### [мямОбщегоНазначения](docs/мямОбщегоНазначения.md)

Серверные операции с метаданными, реквизитами, табличными данными и объектами информационной базы.

### [мямОбщегоНазначенияВызовСервера](docs/мямОбщегоНазначенияВызовСервера.md)

Серверные методы, доступные с клиента, для чтения реквизитов, описаний типов и состава метаданных.

### [мямОбщегоНазначенияКлиент](docs/мямОбщегоНазначенияКлиент.md)

Находит таблицу управляемой формы для работы из клиентского кода.

### [мямОбщегоНазначенияКлиентСервер](docs/мямОбщегоНазначенияКлиентСервер.md)

Формирует описания типов и предоставляет общие операции со значениями для клиентского и серверного кода.

### [мямПроверкаЗаполненияКлиент](docs/мямПроверкаЗаполненияКлиент.md)

Проверяет обязательные поля формы, объекта и табличных частей. Формирует список пропусков и устанавливает отказ при ошибке.

### [мямРеквизитыФормыСервер](docs/мямРеквизитыФормыСервер.md)

Программно создаёт, изменяет и удаляет реквизиты управляемой формы, в том числе реквизиты таблиц.

### [мямСоответствиеКлиентСервер](docs/мямСоответствиеКлиентСервер.md)

Сортирует элементы соответствия по ключу.

### [мямСписокЗначенийКлиентСервер](docs/мямСписокЗначенийКлиентСервер.md)

Создаёт список значений при необходимости и добавляет значение без повтора.

### [мямСсылкаКлиентСервер](docs/мямСсылкаКлиентСервер.md)

Очищает переданную переменную ссылочного типа.

### [мямСтрокаКлиентСервер](docs/мямСтрокаКлиентСервер.md)

Обрабатывает пробелы и символы, проверяет цифры, преобразует имена в синонимы и обратно.

### [мямСтруктураКлиентСервер](docs/мямСтруктураКлиентСервер.md)

Инициализирует структуру, если в переданной переменной находится Неопределено.

### [мямФоновыеЗаданияВызовСервера](docs/мямФоновыеЗаданияВызовСервера.md)

Позволяет администратору проверить наличие и отменить активные фоновые задания по ключу.

### [мямЧислоКлиентСервер](docs/мямЧислоКлиентСервер.md)

Проверяет и преобразует числовые значения. При разборе строки учитывает формат разделителей и сообщает об ошибках.

### [мямЭлементыФормыСервер](docs/мямЭлементыФормыСервер.md)

Создаёт группы и поля управляемой формы, настраивает их свойства и события, удаляет элементы.
