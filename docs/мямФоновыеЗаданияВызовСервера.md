## Зависимости

Другие модули МЯМ не требуются.
БСП: прямых вызовов не обнаружено.
Сервисы платформы: стандартный глобальный контекст 1С.

Модули подключаются комплектом по зависимостям. Цикл между обработкой значений и общими описаниями типов не требует порядка создания: сначала создайте все модули, затем вставьте код и проверьте конфигурацию.

## Методы

### ОстановитьФоновоеЗадание

Экспортный метод.

```bsl
Процедура ОстановитьФоновоеЗадание(КлючФоновогоЗадания) Экспорт
```

Только для администратора: отменяет активные фоновые задания всех пользователей по ключу. Проверка права
  предшествует чтению; привилегированный режим не включает. Ошибки платформы передаёт вызывающему коду.

Параметры:
 КлючФоновогоЗадания - Строка - ключ отбора активных заданий; пользователь-владелец не ограничивается.

### ФоновоеЗаданиеАктивно

Экспортный метод.

```bsl
Функция ФоновоеЗаданиеАктивно(КлючФоновогоЗадания) Экспорт
```

Только для администратора: проверяет наличие активных фоновых заданий любого пользователя по ключу. Проверка
  права предшествует чтению; привилегированный режим не включает.

Параметры:
 КлючФоновогоЗадания - Строка - ключ отбора заданий всех пользователей.

Возвращаемое значение:
 Булево - есть хотя бы одно активное задание; отсутствие права вызывает исключение.
