## Методы

### ЗначениеВЧисло

Экспортный метод.

```bsl
Функция ЗначениеВЧисло(Знач Значение, ФорматИсточника = "") Экспорт
```

Сохраняет числовой аргумент либо строго разбирает строку. Не заменяет пустоту и ошибку нулём.

Параметры:
 Значение - Число, Строка - исходное значение; прочие типы вызывают исключение.
 ФорматИсточника - Строка - см. РазобратьЧисло; используется для строк.

Возвращаемое значение:
 Число - исходное или разобранное число.

### ОчиститьЗначениеЧисла

Экспортный метод.

```bsl
Процедура ОчиститьЗначениеЧисла(ЧислоЗначение) Экспорт
```

Процедура - Очистить значение числа.

Параметры:
 ЧислоЗначение - Число.
  Переданной переменной безусловно присваивается ноль.


### РазобратьЧисло

Экспортный метод.

```bsl
Функция РазобратьЧисло(Сырое, ФорматИсточника = "") Экспорт
```

Разбирает десятичное число без зависимости от региональных настроек. Неверный ввод, пустота и потеря
  точности вызывают исключение; ноль остаётся нулём. Экспонента здесь не поддерживается.

Параметры:
 Сырое - Строка - число с ведущим знаком или бухгалтерскими скобками.
 ФорматИсточника - Строка - пусто: точка/запятая десятичные; Точка или Запятая: явный десятичный
  разделитель, противоположный служит группировке по три цифры.

Возвращаемое значение:
 Число - точное значение в пределах 38 разрядов и 38 дробных позиций.
