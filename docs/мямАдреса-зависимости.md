# Зависимости мямАдреса

[← Модуль и контракт](мямАдреса.md) · [Библиотека](../README.md)

Схемы ниже совпадают в основной конфигурации Trade и исходнике-поставщике. Все пять регистров входят в штатную подсистему АдресныйКлассификатор БСП 3.1.12.323. Эти регистры и их записи не копируются в библиотеку: требуется установленный и загруженный локальный классификатор.

Строения хранит ХранилищеЗначения с текстовыми блоками БСП: UUID кодируется 24-символьным префиксом; следующие части дома/строений разделены табуляцией, тип и номер — Символы.НПП. Формат сверён со штатным разбором АдресныйКлассификаторСлужебный. Схема регистра сама по себе не гарантирует этот формат: после обновления БСП требуется повторная сверка.

ДополнительныеАдресныеСведения в результате — таблица запроса с колонками Идентификатор, КодСубъектаРФ, ПочтовыйИндекс, ОКТМО, OKATO, КодУчасткаИФНСЮЛ, КодУчасткаИФНСФЛ, КодИФНСЮЛ, ОКТМОБюджетополучателя, КодИФНСФЛ; типы указаны у одноимённого регистра выше. Исходная пустая таблица до выполнения запроса колонок не содержит.

## Границы подключения

Создайте общий модуль мямАдреса со свойствами из карточки, вставьте BSL, проверьте перечисленные API и поля регистров в своей конфигурации. Не создавайте пустые замены регистров ради компиляции: без штатного формата/данных результаты не будут полными. Доступ — обычный пользовательский, без привилегированного режима. Платформенный импорт, исполнение на 8.3.27/8.5, работа с реальными адресами, полнота локального классификатора и производительность в принимающей базе не проверялись.
