# мямZIP

[← К оглавлению библиотеки](../README.md) · [Исходный модуль BSL](../modules/мямZIP.bsl) · [Переход ZIP/XLSX](ZIP-XLSX-migration.md)

## Назначение и подключение

Серверный модуль читает ограниченное подмножество ZIP STORE/DEFLATE и формирует ZIP STORE целиком в памяти. Создайте общий модуль мямZIP с указанными свойствами и вставьте исходный BSL. Другие общие модули и БСП ему не требуются; используются встроенные двоичные буферы и функции платформы. Два метода экспортные, остальные 22 — внутренние помощники.

## Вход, результат и владение

`Прочитать` принимает самостоятельные `ДвоичныеДанные`, а не путь, поток или `ЧтениеZipФайла`. Возвращает `Структура` с массивом `Элементы`: у каждой записи `ПолноеИмя`, `РазмерНесжатого`, `Данные`. Данные записей независимы от входного буфера. Вход не меняется. Никаких временных каталогов, внешних компонентов или COM модуль не создаёт.

`Сформировать` принимает массив структур `ПолноеИмя,Данные` и возвращает `ДвоичныеДанные`. Исходный массив/данные остаются у вызывающего кода; модуль их не сохраняет. Для результата не требуется `Закрыть()`: память освобождается по обычному жизненному циклу значений и ссылок.

## Поддерживаемое подмножество и пределы

Чтение поддерживает однодисковый ZIP с методами STORE (0) и DEFLATE (8), проверкой CRC32 и согласованными локальными/центральными заголовками. DEFLATE включает несжатые блоки, фиксированные и динамические коды. Дескриптор данных проверяется в 12- и 16-байтовой форме. ZIP64, шифрование, несколько дисков и другие методы сжатия отклоняются. Префикс/самораспаковывающаяся оболочка, скрытые записи, разрывы и перекрытия записей также отклоняются. Это описание реализации, а не обещание прочитать любой допустимый ZIP.

| Операция | Пределы |
|---|---|
| Прочитать | Вход 22..16777216 байтов (16 МиБ); по умолчанию до 67108864 распакованных байтов (64 МиБ) суммарно и в одной записи; до 1000 записей, включая каталоги |
| Параметры чтения | Можно ужесточить ограничения: ПределАрхива 22..16777216, ПределДанных 0..67108864, ПределЗаписей 0..1000; значения целые |
| Сформировать | До 1000 записей, каждая до 64 МиБ; выход со всеми заголовками до 134217728 байтов (128 МиБ); UTF-8 имя до 65535 байтов |

Запись всегда STORE с UTF-8 флагом и датой 01.01.1980. Пустой массив даёт пустой ZIP. Записанный файл может превышать предел чтения этого же модуля: для последующего чтения соблюдайте также его ограничения. Пиковая память зависит от одновременно хранимых входа, выходных буферов и записей; предел данных не является обещанием такого же предела оперативной памяти.

Имена относительные, разделитель `/`. Абсолютное имя, `\`, `:`, управляющие символы, пустые сегменты, `.` и `..` запрещены. Запись каталога завершается `/` и имеет нулевые данные. Повторы отвергаются без учёта регистра, в том числе совпадение файла и имени каталога без конечного `/`. Имена без флага UTF-8 допускают только ASCII; UTF-8 проверяется обратным кодированием. Повреждение, неподдерживаемые признаки или превышение предела вызывают исключение; частичного массива чтения метод не возвращает.

## Пример серверного вызова

```bsl
Элементы = Новый Массив;
ДанныеТекста = ПолучитьДвоичныеДанныеИзСтроки("Пример", КодировкаТекста.UTF8, Ложь);
Элементы.Добавить(Новый Структура("ПолноеИмя,Данные", "data.txt", ДанныеТекста));
ДанныеZIP = мямZIP.Сформировать(Элементы);
Архив = мямZIP.Прочитать(ДанныеZIP);
ПерваяЗапись = Архив.Элементы[0];
```

## Проверка в принимающей конфигурации

Методы выполняют обработку в памяти и не создают временных каталогов. Это свойство исходного кода, а не подтверждение работы всей конфигурации в безопасном режиме. После подключения проверьте компиляцию на своей версии платформы, чтение и запись поддерживаемых файлов, права/RLS, ограничения памяти и времени, а также используемые защиты. Исходные проверки и модели не заменяют такую приёмку. Не отключайте защиты ради этих модулей.

## Основания формата

Названия записей ZIP соотносятся с [PKWARE APPNOTE 6.3.10 FINAL](https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT); описание DEFLATE находится в [RFC 1951, раздел 3.2](https://www.rfc-editor.org/rfc/rfc1951). RFC имеет статус Informational. Эти документы приведены ссылками, без воспроизведения их текста. Пределы, проверки и исключённые возможности выше принадлежат данной реализации; полного соответствия всем возможностям форматов не заявляется.

## Методы

### CRC32

Внутренний помощник.

```bsl
Функция CRC32(Буфер, Таблица)
```

По Буфер и Таблица CRC32 возвращает Число контрольной суммы. Входы не меняет; CRC32 используется для проверки целостности записей, не для криптографической защиты.

### Биты

Внутренний помощник.

```bsl
Функция Биты(Состояние, Количество)
```

Читает Количество битов из Состояние (Структура с Буфер, Бит, КонецБит), возвращает Число и увеличивает Бит. При выходе за предел вызывает исключение; состояние может быть уже продвинуто, откат не предусмотрен.

### Дерево

Внутренний помощник.

```bsl
Функция Дерево(Длины, Кодовое = Ложь)
```

По массиву Длины и признаку Кодовое строит проверенную структуру канонического дерева кодов. Возвращает Структура; входные длины не меняет. Недопустимое дерево вызывает исключение.

### ДинамическиеДеревья

Внутренний помощник.

```bsl
Функция ДинамическиеДеревья(Состояние)
```

Читает динамические деревья из Состояние, продвигая его битовую позицию. Возвращает Структура Литералы, Расстояния. Неверные длины, повторы или деревья вызывают исключение.

### ДлинаДескриптора

Внутренний помощник.

```bsl
Функция ДлинаДескриптора(Буфер, Начало, Предел, Контроль, Сжато, Размер)
```

Сверяет дескриптор в Буфер по Начало и Предел с ожидаемыми Контроль, Сжато, Размер. Возвращает Число 12 или 16; не меняет буфер. Несовпадение вызывает исключение.

### ЗаписатьLE

Внутренний помощник.

```bsl
Процедура ЗаписатьLE(Буфер, Позиция, Знач Значение, Знач Размер)
```

Записывает Значение в Буфер по текущей Позиция, используя Размер байтов от младшего к старшему. Позиция передана по ссылке и увеличивается; Значение/Размер переданы по значению. Место заранее рассчитывает вызывающий внутренний код. Значения не возвращает.

### ЗаписиАрхива

Внутренний помощник.

```bsl
Функция ЗаписиАрхива(Буфер, КонецКаталога, ПределДанных, ПределЗаписей)
```

Проверяет центральный каталог и локальные заголовки в Буфер, начиная с выбранного КонецКаталога, с ПределДанных и ПределЗаписей. Возвращает массив описаний имени, размеров, метода, CRC и смещений. Не распаковывает и не меняет буфер; нарушение связей/пределов вызывает исключение.

### КандидатКонцаКаталога

Внутренний помощник.

```bsl
Функция КандидатКонцаКаталога(Буфер, Позиция)
```

Проверяет по Буфер и Позиция, может ли запись быть концом согласованного центрального каталога. Возвращает Булево; не выделяет массив выходных данных. Истинный результат не заменяет распаковку и проверку CRC.

### КопияБайтов

Внутренний помощник.

```bsl
Функция КопияБайтов(Буфер, Начало, Размер)
```

Создаёт независимый БуферДвоичныхДанных из диапазона Буфер, Начало, Размер. Проверяет границы; исходный буфер не меняет, нарушение вызывает исключение.

### НайтиЗаписиАрхива

Внутренний помощник.

```bsl
Функция НайтиЗаписиАрхива(Буфер, ПределДанных, ПределЗаписей)
```

Ищет проверенный конец центрального каталога от конца Буфер, учитывая ПределДанных и ПределЗаписей. Возвращает массив описаний записей, без распаковки. Вход не меняет; отсутствие подходящего кандидата вызывает исключение.

### ОшибкаZIP

Внутренний помощник.

```bsl
Процедура ОшибкаZIP(Причина = "")
```

Формирует исключение ZIP. Причина — Строка, необязательное уточнение. Не возвращает значение и не изменяет входы.

### ПеренестиБайты

Внутренний помощник.

```bsl
Процедура ПеренестиБайты(Выход, Позиция, Источник)
```

Копирует Источник (БуферДвоичныхДанных) в Выход по Позиция. Меняет Выход и увеличивает Позиция по ссылке; Источник не меняет. Достаточную ёмкость обеспечивает вызывающий внутренний код. Значения не возвращает.

### ПроверитьГраницы

Внутренний помощник.

```bsl
Процедура ПроверитьГраницы(Буфер, Начало, Размер)
```

Проверяет диапазон Начало, Размер в Буфер (БуферДвоичныхДанных). Отрицательная величина или выход за границу вызывает исключение. Буфер не изменяет.

### ПроверитьДополнение

Внутренний помощник.

```bsl
Процедура ПроверитьДополнение(Буфер, Начало, Размер)
```

Проверяет границы и длины полей дополнения в диапазоне Буфер, Начало, Размер; отклоняет признаки ZIP64 и шифрования. Буфер не изменяет, неверное поле вызывает исключение. Значения не возвращает.

### ПроверитьИмя

Внутренний помощник.

```bsl
Процедура ПроверитьИмя(Имя, Имена)
```

Проверяет Имя (Строка) и добавляет его нормализованный ключ в Имена (Соответствие) после успешной проверки. При неверном имени или повторе вызывает исключение; строку не изменяет. Значения не возвращает.

### ПроверитьПредел

Внутренний помощник.

```bsl
Процедура ПроверитьПредел(Значение, Минимум, Максимум)
```

Проверяет, что Значение — целое Число между Минимум и Максимум включительно. Входы не меняет; нарушение вызывает исключение.

### Прочитать

Экспортный метод.

```bsl
Функция Прочитать(Данные, ПределАрхива = 16777216, ПределДанных = 67108864, ПределЗаписей = 1000) Экспорт
```

Читает ZIP целиком, проверяет все записи и возвращает их двоичные данные.
Параметры:
 Данные - ДвоичныеДанные - ZIP без префикса/самораспаковывающейся оболочки.
 ПределАрхива - Число - целое 22..16777216, предел входных байтов.
 ПределДанных - Число - целое 0..67108864, общий и построчный предел распаковки.
 ПределЗаписей - Число - целое 0..1000, включая записи каталогов.
Возвращаемое значение:
 Структура - Элементы: Массив структур ПолноеИмя, РазмерНесжатого, Данные.
  Имена относительные, разделитель /; каталог обозначается завершающим /.
  Данные - ДвоичныеДанные, независимые от входного буфера.
Ошибки: исключение при нарушении формата/лимита. ZIP64, шифрование, несколько
дисков, методы кроме STORE/DEFLATE и не-ASCII имена без UTF-8 флага не поддерживаются.
UTF-8 проверяется обратным кодированием. Дубликаты, включая регистровые, запрещены.

### ПрочитатьИмя

Внутренний помощник.

```bsl
Функция ПрочитатьИмя(Буфер, Начало, Размер, Флаги)
```

Декодирует диапазон Буфер, Начало, Размер с учётом Флаги. Возвращает Строка; без UTF-8 флага принимает только ASCII, UTF-8 проверяет обратным кодированием. Вход не меняет; нарушение вызывает исключение.

### Распаковать

Внутренний помощник.

```bsl
Функция Распаковать(Буфер, Начало, Сжато, Размер)
```

Распаковывает DEFLATE из диапазона Буфер, Начало, Сжато в новый БуферДвоичныхДанных размером Размер. Исходный буфер не меняет. Проверяет каждый записываемый блок/символ/обратную ссылку и конечные размеры; нарушение вызывает исключение. Бюджет Размер проверяется вызывающим кодом до выделения результата.

### СимволДерева

Внутренний помощник.

```bsl
Функция СимволДерева(Состояние, ДеревоКодов)
```

Читает следующий символ по Состояние и ДеревоКодов. Возвращает Число, продвигает битовую позицию состояния; неверный код или конец данных вызывает исключение.

### Сформировать

Экспортный метод.

```bsl
Функция Сформировать(Элементы) Экспорт
```

Создаёт ZIP STORE с UTF-8 именами и датой 01.01.1980, без изменения входа.
Параметры:
 Элементы - Массив из Структура - ПолноеИмя (Строка), Данные (ДвоичныеДанные).
  До 1000 записей, каждая до 64 МиБ; выход с заголовками до 128 МиБ.
Возвращаемое значение:
 ДвоичныеДанные - завершённый ZIP. Пустой массив создаёт пустой архив.
Ошибки: исключение при неверном имени, дубликате, типе или превышении лимита.
Вызывающий код владеет входным массивом и возвращёнными данными; модуль их не сохраняет.

### ТаблицаCRC32

Внутренний помощник.

```bsl
Функция ТаблицаCRC32()
```

Параметров нет. Возвращает Массив из 256 чисел для расчёта CRC32; внешние значения не изменяет.

### ФиксированныеДеревья

Внутренний помощник.

```bsl
Функция ФиксированныеДеревья()
```

Параметров нет. Возвращает Структура Литералы, Расстояния с фиксированными деревьями DEFLATE; внешние значения не изменяет.

### ЧислоLE

Внутренний помощник.

```bsl
Функция ЧислоLE(Буфер, Начало, Размер)
```

Читает Число из Буфер по Начало и Размер в порядке от младшего байта к старшему. Проверяет границы, вход не меняет; неверный диапазон вызывает исключение.
