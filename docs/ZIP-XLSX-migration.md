# Переход на ZIP/XLSX в памяти

[← К библиотеке](../README.md) · [мямZIP](мямZIP.md) · [мямXLSX](мямXLSX.md)

## Что обновить

Этап 7 каталога переносит проверенные исходники ZIP/XLSX из расширения Trade от 6 ноября 2026 года без изменения алгоритмов. Исходный commit донора: `95bf2b3ec881b268f3859952440ab5845e3adc99`. В библиотеку не входят бизнес-объекты расширения. Полные мямСтрокаКлиентСервер и мямЧислоКлиентСервер сохранены, включая методы, отсутствующие у потребителя.

Обновите мямXLSX, добавьте мямZIP и подключите зависимости по каталогам. Оба архивных модуля — серверные, без привилегий, внешнего соединения и прямого вызова сервера. БСП ФайловаяСистема больше не является зависимостью XLSX. Не меняйте настройки защиты для подключения.

## Совместимость вызовов

| Поверхность | Изменение |
|---|---|
| НоваяКнигаXLSX, ДобавитьЛистXLSX, УстановитьЯчейкуXLSX, СформироватьXLSX | Сигнатуры сохранены; сборка ZIP выполняется в памяти |
| ПрочитатьКнигуXLSX | Добавлен необязательный ТолькоПервыйЛист = Ложь; старый вызов с одним аргументом остаётся допустимым |
| XMLИзАрхива, ЧастиКнигиXLSX | Число параметров сохранено, но Архив теперь Структура из мямZIP.Прочитать, а не ЧтениеZipФайла: это изменение типа во время выполнения |
| КаталогЧтения | Обязательный по сигнатуре строковый параметр низкоуровневых методов, зарезервирован и не используется; передавайте "" |
| ПредупрежденияОчистки | Поле результата сохранено; в реализации в памяти всегда пустой массив |

Одинаковое число аргументов не гарантирует совместимость старого низкоуровневого кода. Объект ЧтениеZipФайла в новые методы не передавайте. Для новых потребителей предпочтительно высокоуровневое чтение:

```bsl
Результат = мямXLSX.ПрочитатьКнигуXLSX(ДанныеФайла);
```

ДанныеФайла — ДвоичныеДанные. Проверьте ОшибкаЧтения книги и листов, как показано в каталоге мямXLSX. При необходимости первого листа явно передайте Истина вторым аргументом. Это не ограничивает предварительную распаковку ZIP; описания остальных листов сохраняются в результате, но их строки не читаются.

Если вы работали с отдельными частями, замените создание нативного ZIP-читателя на результат собственного модуля:

```bsl
Архив = мямZIP.Прочитать(ДанныеФайла);
Части = мямXLSX.ЧастиКнигиXLSX(Архив, "");
КорневыеСвязи = мямXLSX.XMLИзАрхива(Архив, "_rels/.rels", "");
```

Архив принадлежит вызывающему коду и содержит записи в памяти. Для него нет Закрыть(); старую очистку созданного вами временного каталога не переносите в новую схему без такого ресурса. Низкоуровневые методы по-прежнему могут вызвать исключение, в отличие от результата высокоуровневого чтения с полями ошибок.

## Внутренние изменения

Внутренние методы не являются внешним программным интерфейсом. Если потребитель всё же их вызывал, нужна отдельная миграция:

- `ЗаписатьXMLЧастьXLSX(ИмяФайла, XMLЧасти)` заменён на `ЗаписатьXMLЧастьXLSX(Части, ИмяЧасти, XMLЧасти)`: вместо пути используется структура сборки в памяти.
- `ЗаписатьЧастиКнигиXLSX(Книга, КаталогСборки)` теперь принимает `(Книга, Части)`.
- `ОчиститьРесурсыЗаписиXLSX` удалён. Добавлены внутренние проверки бюджетов, однопроходное декодирование ST_Xstring и геометрия объединений.

Текст inline/shared strings и строковый кэш формул декодируются однократно. Дата 0 в системе 1904 теперь распознаётся как 01.01.1904; фиктивный день 60 системы 1900 остаётся недопустимым. Ячейки результата полного чтения дополнены ПраваяКолонка и НижняяСтрока; существующие значения не распространяются по объединённым ячейкам.

## Ограничения и приёмка

Сверьте входы с каталогами: поддерживается ограниченный ZIP STORE/DEFLATE, без ZIP64/шифрования/нескольких дисков; чтение XLSX — до 16 МиБ ZIP, 64 МиБ распаковки, 1000 записей, 20 листов и 20000 строк. Запись может сформировать ZIP до 128 МиБ и не означает, что такой файл пройдёт чтение с меньшими пределами. Бинарный XLS, XLSM и полный OOXML не поддерживаются.

Перед заменой в принимающей конфигурации сохраните её исходную версию, проверьте компиляцию, свои корректные/повреждённые файлы, однопараметрические вызовы, новые низкоуровневые вызовы и обработку частичных ошибок. Отдельно проверьте память/время, права/RLS, пользовательские сценарии и обе используемые защиты. Обработка в памяти не доказывает работу всего потребителя в безопасном режиме. Полный нативный Check/приёмка этой библиотечной поставки здесь не заявляются.
