## Методы

### ДобавитьУникальноеЗначение

Экспортный метод.

```bsl
Функция ДобавитьУникальноеЗначение(ПроверяемыйСписок,Знач ДобавляемоеЗначение,Знач ДобавляемоеПредставление="",Знач ДобавляемаяПометка=Ложь,Знач ДобавляемаяКартинка=Неопределено) Экспорт
```

Функция - Добавить уникальное значение.

Параметры:
 ПроверяемыйСписок - СписокЗначений.
  Дополняет переданный список только при отсутствии ДобавляемогоЗначения.
 ДобавляемоеЗначение - Произвольное.
 ДобавляемоеПредставление - Строка, ФорматированнаяСтрока.
 ДобавляемаяПометка - Булево.
 ДобавляемаяКартинка - Картинка. По умолчанию - Неопределено.

Возвращаемое значение:
  - СписокЗначений.


### ЕслиСписокЗначенийНеопределеноТоНовый

Экспортный метод.

```bsl
Процедура ЕслиСписокЗначенийНеопределеноТоНовый(ПроверяемыйСписокЗначений) Экспорт
```

Процедура - Если список значений неопределено то новый.
 Если значение "Неопределено", тогда значение заменяется на пустой список значений.

Параметры:
 ПроверяемыйСписокЗначений  - Неопределено, СписокЗначений.
  Если передано Неопределено, заменяет переданную переменную новым пустым списком значений; другое значение сохраняет.
