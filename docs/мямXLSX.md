## Методы

### XMLИзАрхива

Экспортный метод.

```bsl
Функция XMLИзАрхива(Архив, ИмяЧасти, КаталогЧтения) Экспорт
```

Читает UTF-8 XML из проверенного архива в отдельную подпапку, без восстановления путей. Отсутствующая
  часть, DTD или ошибка XML вызывает исключение; архив не закрывает.

Параметры:
 Архив - ЧтениеZipФайла - архив, проверенный ЧастиКнигиXLSX.
 ИмяЧасти - Строка - разрешённое имя ZIP-части, не путь файловой системы.
 КаталогЧтения - Строка - временный каталог владельца с завершающим разделителем; создаёт подпапку.

Возвращаемое значение:
 ДокументDOM - разобранный документ части.

### XMLЛистаЗаписиXLSX

Внутренний помощник.

```bsl
Функция XMLЛистаЗаписиXLSX(Лист)
```

Упорядочивает заполненные ячейки по координатам и формирует лист без пустых промежуточных строк.

Параметры:
 Лист - Структура - см. ДобавитьЛистXLSX; не изменяется.

Возвращаемое значение:
 Строка - XML worksheet с sheetData.

### XMLЯчейкиЗаписиXLSX

Внутренний помощник.

```bsl
Функция XMLЯчейкиЗаписиXLSX(Адрес, Значение)
```

Формирует XML одной ячейки без формул; дату переводит в систему Excel 1900 с поправкой на фиктивный
  день.

Параметры:
 Адрес - Строка - проверенный адрес ячейки.
 Значение - Строка, Число, Булево, Дата - проверенное непустое значение.

Возвращаемое значение:
 Строка - элемент c; строка записана как inlineStr, дата со стилем 1.

### АдресЯчейкиЗаписиXLSX

Внутренний помощник.

```bsl
Функция АдресЯчейкиЗаписиXLSX(НомерСтроки, НомерКолонки)
```

Строит адрес ячейки из проверенных координат.

Параметры:
 НомерСтроки - Число - целый номер строки с единицы.
 НомерКолонки - Число - целый номер колонки с единицы.

Возвращаемое значение:
 Строка - адрес вида AA17.

### БуквыКолонки

Внутренний помощник.

```bsl
Функция БуквыКолонки(АдресЯчейки)
```

Выделяет буквенную часть адреса ячейки. Отсутствие букв или длина больше трёх вызывает исключение.

Параметры:
 АдресЯчейки - Строка - адрес вида AA17 с заглавными латинскими буквами.

Возвращаемое значение:
 Строка - буквы колонки; номер строки проверяет вызывающий метод.

### ВнутренняяЧасть

Внутренний помощник.

```bsl
Функция ВнутренняяЧасть(Архив, Источник, Связь)
```

Разрешает цель внутренней связи и проверяет наличие части. Внешний/неизвестный режим и отсутствие части
  вызывают исключение.

Параметры:
 Архив - ЧтениеZipФайла - проверенный архив.
 Источник - Строка - имя части-источника либо пусто для корня.
 Связь - Структура - Тип, Цель, Режим из ПрочитатьСвязи.
  У внутренней связи РазрешитьЦель удаляет начальный / из свойства Цель, если он есть; свойство меняется и при последующей ошибке пути или отсутствии части архива.

Возвращаемое значение:
 Строка - имя существующей ZIP-части.

### ДатаExcel

Внутренний помощник.

```bsl
Функция ДатаExcel(Сырое, Даты1904)
```

Переводит целую часть серийной даты в календарную строку. Неверные значения и фиктивный день 1900-02-29
  не принимает.

Параметры:
 Сырое - Строка - серийное число Excel.
 Даты1904 - Булево - использовать начало отсчёта 1904 вместо 1900.

Возвращаемое значение:
 Строка - dd.MM.yyyy либо пустая строка при отказе.

### ДобавитьЛистXLSX

Экспортный метод.

```bsl
Функция ДобавитьЛистXLSX(Книга, ИмяЛиста) Экспорт
```

Добавляет лист в конец книги. Неверное имя или повтор без учёта регистра вызывает исключение до
  изменения книги.

Параметры:
 Книга - Структура - см. НоваяКнигаXLSX; дополняет ЛистыXLSX.
  После проверки книги, имени и отсутствия повтора добавляет новый лист в переданный массив ЛистыXLSX.
 ИмяЛиста - Строка - имя длиной 1–31 единица UTF-16, кроме History; см. ПроверитьИмяЛистаXLSX.

Возвращаемое значение:
 Структура - ИмяXLSX (Строка), ЯчейкиXLSX (Соответствие ключа координаты и значения). Заполнять через
  УстановитьЯчейкуXLSX.

### ДобавитьТипСодержимого

Внутренний помощник.

```bsl
Процедура ДобавитьТипСодержимого(Типы, Ключ, Узел)
```

Добавляет описание ContentType, отклоняя пустые, повторные или чужие элементы исключением.

Параметры:
 Типы - Соответствие - дополняемый индекс частей или расширений → ContentType.
  В переданное соответствие добавляет новую пару после проверки узла; любой существующий ключ вызывает исключение до вставки.
 Ключ - Строка - нормализованное имя части либо расширение.
 Узел - ЭлементDOM - Override или Default из [Content_Types].xml.

### ЗаписатьXMLЧастьXLSX

Внутренний помощник.

```bsl
Процедура ЗаписатьXMLЧастьXLSX(ИмяФайла, XMLЧасти)
```

Записывает XML-часть в UTF-8 с декларацией. Закрывает запись и при ошибке; сбой закрытия сохраняет
  первичную причину.

Параметры:
 ИмяФайла - Строка - полный путь создаваемого файла.
 XMLЧасти - Строка - содержимое XML без декларации.

### ЗаписатьЧастиКнигиXLSX

Внутренний помощник.

```bsl
Процедура ЗаписатьЧастиКнигиXLSX(Книга, КаталогСборки)
```

Создаёт на диске части XLSX: листы, книгу, стили, связи и типы содержимого. Ошибки файловой системы
  передаются вызывающему методу.

Параметры:
 Книга - Структура - проверенная книга с листами, не изменяется.
 КаталогСборки - Строка - временный каталог с завершающим разделителем; создаёт вложенные папки и файлы.

### НайтиСтилиДат

Внутренний помощник.

```bsl
Функция НайтиСтилиДат(Стили)
```

Распознаёт стандартные форматы 14–22 и пользовательские форматы с yy и d.

 Соответствие - строковый индекс ячейкового стиля → Истина для распознанной даты.

Параметры:

 ИмяЧасти - Строка - разрешённое имя ZIP-части.

Возвращаемое значение:
 ЭлементZipФайла, Неопределено - найденная запись либо отсутствие.

### НеобязательнаяЧасть

Внутренний помощник.

```bsl
Функция НеобязательнаяЧасть(Архив, Источник, Связи, Тип, Корень, Каталог)
```

Читает необязательную часть по типу связи и проверяет её корень. Отсутствие допустимо; повреждение
  найденной части вызывает исключение.

Параметры:
 Архив - ЧтениеZipФайла - проверенный архив.
 Источник - Строка - имя части книги.
 Связи - Соответствие - связи книги.
 Тип - Строка - короткий тип связи.
 Корень - Строка - ожидаемое имя корня.
 Каталог - Строка - временный каталог извлечения с завершающим разделителем.

Возвращаемое значение:
 ДокументDOM, Неопределено - прочитанная часть либо отсутствие связи.

### НоваяКнигаXLSX

Экспортный метод.

```bsl
Функция НоваяКнигаXLSX() Экспорт
```

Создаёт независимую книгу для заполнения на сервере. Книгу и листы следует менять методами этого модуля;
  память зависит от числа и объёма ячеек.

Возвращаемое значение:
 Структура - ЛистыXLSX (Массив листов); изначально листов нет. См. ДобавитьЛистXLSX.

### ОчиститьРесурсыЗаписиXLSX

Внутренний помощник.

```bsl
Функция ОчиститьРесурсыЗаписиXLSX(АрхивЗаписи, КаталогСборки)
```

Завершает архив и удаляет каталог даже при ошибке завершения. Ошибки очистки возвращает текстом, не
  скрывая их.

Параметры:
 АрхивЗаписи - ЗаписьФайлаАрхива, Неопределено - незавершённый архив.
 КаталогСборки - Строка - временный каталог, подлежащий удалению.

Возвращаемое значение:
 Строка - сообщения ошибок с переводами строк либо пустая строка.

### ПроверитьАрхив

Внутренний помощник.

```bsl
Процедура ПроверитьАрхив(Архив)
```

Отклоняет исключением небезопасные/повторные имена, более 1000 записей или общий размер без сжатия свыше
  64 МиБ. Регистровые коллизии также запрещены.

Параметры:
 Архив - ЧтениеZipФайла - открытый архив; не изменяется и не закрывается.

### ПроверитьЗначениеЯчейкиXLSX

Внутренний помощник.

```bsl
Процедура ПроверитьЗначениеЯчейкиXLSX(Значение)
```

Проверяет поддерживаемый тип, длину/символы строки, точность числа и нижнюю границу даты. Нарушение
  вызывает исключение до записи ячейки.

Параметры:
 Значение - Строка, Число, Булево, Дата, Неопределено, Null - новое значение; см. УстановитьЯчейкуXLSX.

### ПроверитьИмяЛистаXLSX

Внутренний помощник.

```bsl
Процедура ПроверитьИмяЛистаXLSX(ИмяЛиста)
```

Проверяет имя листа до изменения книги: длину, символы, крайние апострофы, History и пробельное имя.
  Нарушение вызывает исключение.

Параметры:
 ИмяЛиста - Строка - предлагаемое имя листа, не изменяется; уникальность проверяется отдельно.

### ПроверитьКнигуЗаписиXLSX

Внутренний помощник.

```bsl
Процедура ПроверитьКнигуЗаписиXLSX(Книга)
```

Отклоняет исключением значение без массива листов книги.

Параметры:
 Книга - Структура - ожидается поле ЛистыXLSX типа Массив; значение не изменяется.

### ПроверитьКоординатуXLSX

```bsl
Процедура ПроверитьКоординатуXLSX(Координата, Максимум)
```

 Максимум - Число - верхняя граница включительно.

### ПроверитьЛистЗаписиXLSX

```bsl
Процедура ПроверитьЛистЗаписиXLSX(Лист)
```

### ПроверитьСимволыПути

Внутренний помощник.

```bsl
Процедура ПроверитьСимволыПути(Имя)
```

Запрещает неоднозначные символы пути OOXML, включая проценты, управляющие символы и двойную косую черту.

Параметры:
 Имя - Строка - имя записи или цель связи; не изменяется.

### ПроверитьТекстЗаписиXLSX

```bsl
Процедура ПроверитьТекстЗаписиXLSX(Текст)
```

Отклоняет исключением запрещённые XML 1.0 символы и непарные суррогатные единицы UTF-16.

Параметры:
 Текст - Строка - текст ячейки или имя листа; не изменяется.

### ПроверитьТипКниги

```bsl
Процедура ПроверитьТипКниги(Архив, ИмяКниги, Каталог)
```

Параметры:
 Архив - ЧтениеZipФайла - проверенный архив.
 ИмяКниги - Строка - разрешённое имя workbook.
 Каталог - Строка - временный каталог извлечения с завершающим разделителем.

### ПрочитатьСвязи

Внутренний помощник.

```bsl
Функция ПрочитатьСвязи(Архив, Имя, Каталог)
```

Читает Relationships, проверяя обязательные атрибуты и уникальность Id. Повреждение вызывает исключение.

Параметры:

 Имя - Строка - имя части связей в ZIP.
 Каталог - Строка - временный каталог для извлечения с завершающим разделителем.

Возвращаемое значение:
 Соответствие - Id → Структура (Тип, Цель, Режим); отсутствующий TargetMode означает Internal.

```bsl
Функция ПутьЛиста(Связи, ЛистКниги)
```

Параметры:

 ЛистКниги - ЭлементDOM - элемент sheet книги.

Возвращаемое значение:
 Строка, Неопределено - имя части либо отсутствие соответствия.

### РазрешитьЦель

Внутренний помощник.

```bsl
Функция РазрешитьЦель(Источник, Цель)
```

Разрешает . и .. относительно части-источника либо корня пакета. Пустой сегмент и выход за корень
  вызывают исключение.

Параметры:
 Источник - Строка - имя ZIP-части, пусто для корня.
 Цель - Строка - Target связи; при корневой цели удаляет начальную косую черту в параметре.
  После проверки символов удаляет начальный / из самой переданной переменной, если он есть; изменение сохраняется при последующей ошибке пути.

Возвращаемое значение:
 Строка - нормализованное внутреннее имя ZIP-части.

### СвязьПоТипу

Внутренний помощник.

```bsl
Функция СвязьПоТипу(Связи, ИмяТипа, Обязательная = Ложь)
```

Выбирает единственную связь заданного типа. Повтор и отсутствие обязательной связи вызывают исключение.

Параметры:
 Связи - Соответствие - результат ПрочитатьСвязи.
 ИмяТипа - Строка - короткое имя типа для ТипСвязи.
 Обязательная - Булево - запрещает отсутствие связи.

Возвращаемое значение:
 Структура, Неопределено - Тип, Цель, Режим найденной связи либо отсутствие.

### СформироватьXLSX

Экспортный метод.

```bsl
Функция СформироватьXLSX(Книга) Экспорт
```

Собирает полный Transitional XLSX во временном каталоге, не меняя книгу. Пустая книга, ошибка записи,
  архива или очистки вызывает исключение с причиной. Даты записывает в системе 1900 до секунды.

Параметры:
 Книга - Структура - заполненная НоваяКнигаXLSX хотя бы с одним листом.

Возвращаемое значение:
 ДвоичныеДанные - полный ZIP книги; пиковая память зависит от ячеек, XML и архива. Открытие файла в
  Excel и нативная проверка требуют отдельной приёмки.

### ПрочитатьМатрицу

Внутренний помощник.

```bsl
Функция ПрочитатьМатрицу(ЛистXML, ОбщиеСтроки, СтилиДат, Даты1904)
```

Декодирует присутствующие строки XML-листа, не вычисляя формулы и не преобразуя числовой текст в число.
Неверное имя или пространство имён корневого элемента вызывает исключение; без sheetData возвращает
пустой массив. Проверки адреса, порядка строк и индекса общей строки могут вызвать исключение;
частичный массив тогда не возвращается. Некорректная серийная дата даёт пустую СохраненнаяДата.
Входные значения не изменяет.

Параметры:
 ЛистXML - ДокументDOM - worksheet в пространстве имён Transitional OOXML; строки по возрастанию до 20000.
 ОбщиеСтроки - Массив из Строка - таблица sharedStrings для ячеек типа s.
 СтилиДат - Соответствие - строковый индекс стиля → Истина для распознанного формата даты.
 Даты1904 - Булево - система дат workbook: Истина для 1904, Ложь для 1900.

Возвращаемое значение:
 Массив из Структура - только присутствующие строки в порядке XML:
  * Номер - Число - исходный номер строки.
  * Ячейки - Соответствие - буквы колонки → Структура ячейки:
    * Текст - Строка - исходное v, общая строка либо текст inlineStr; серийная дата и экспонента остаются текстом.
    * НетКэша - Булево - есть формула без непустого v.
    * ОшибкаExcel - Булево - тип ячейки e.
    * Адрес - Строка - исходный адрес ячейки.
    * Формула - Булево - есть элемент f; формула не вычисляется.
    * СохраненнаяДата - Строка - dd.MM.yyyy либо пусто; используется существующая ДатаExcel.
    * Числовая - Булево - тип отсутствует либо n; это признак, а не результат разбора числа.

ПрочитатьМатрицу — внутренний помощник для уже разобранного XML-листа. Публичный ПрочитатьКнигуXLSX в комплект пока не включён: чтение полной книги из двоичных данных этой поставкой не предоставляется.
