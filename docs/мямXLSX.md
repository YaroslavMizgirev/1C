# мямXLSX

[← К оглавлению библиотеки](../README.md) · [Исходный модуль BSL](../modules/мямXLSX.bsl) · [Переход с прежней версии](ZIP-XLSX-migration.md)

## Назначение и подключение

Модуль читает и формирует ограниченное подмножество Transitional XLSX целиком в памяти. Он не вычисляет формулы: читает сохранённые значения и отмечает отсутствующий кэш. Подключите серверные мямXLSX и [мямZIP](мямZIP.md), а также [мямЧислоКлиентСервер](мямЧислоКлиентСервер.md) и его зависимость [мямСтрокаКлиентСервер](мямСтрокаКлиентСервер.md). У строкового и числового модулей сохраните свойства из их собственных каталогов.

Для мямXLSX и мямZIP БСП не требуется. Прежняя зависимость XLSX от ФайловаяСистема удалена. Вызывайте модуль из серверного кода; свойства ниже не предоставляют прямой клиентский вызов.

## Данные, ошибки и ограничения

Высокоуровневый `ПрочитатьКнигуXLSX` принимает `ДвоичныеДанные`, а не путь или адрес хранилища. Проверяйте `ОшибкаЧтения` книги и каждого листа: при ошибке частичный результат не означает, что книга прочитана полностью. `ПредупрежденияОчистки` оставлено для совместимости и в этой реализации всегда пусто. Архивы и XML не извлекаются в файловую систему, закрывать объект ZIP или удалять временный каталог после вызова не требуется.

| Операция | Ограничения реализации |
|---|---|
| Чтение | ZIP до 16777216 байтов (16 МиБ), не более 1000 записей и 67108864 распакованных байтов (64 МиБ); 1–20 листов, строки до 20000 |
| Запись | До 1000 ZIP-частей, каждая до 64 МиБ, выходной ZIP вместе с заголовками до 134217728 байтов (128 МиБ) |
| Ячейки записи | Строка 1..1048576, колонка 1..16384; строковое значение до 32767 единиц UTF-16; число до 15 значащих цифр; дата не ранее 01.01.1900 |

Предел записи выше предела чтения. Не каждый файл, который можно сформировать, можно затем прочитать этим же модулем. Для такого обмена соблюдайте пересечение ограничений, включая размер ZIP, число листов и строк. Пиковое потребление памяти может превышать размер входа и выхода: одновременно существуют двоичные данные, распакованные части, DOM и структуры ячеек.

Бинарный XLS, XLSM, шифрование и полный OOXML не поддерживаются. Внешние связи, DTD и неоднозначные части пакета отклоняются. Фактическое подмножество ZIP описано в мямZIP; допустимый файл стандарта в целом может не входить в это подмножество.

Текстовые фрагменты inline/shared strings и кэш строковых формул декодируются по ST_Xstring за один проход; буквальные `_xHHHH_` не декодируются повторно после экранированного подчёркивания. Числовые значения остаются текстом, даты дополнительно представлены строкой. Чтение различает системы дат: 1900 — серийные 1..2958465 без фиктивного дня 60, 1904 — 0..2957003; дробная часть дня отбрасывается. Серийный ноль системы 1904 означает 01.01.1904.

Новый необязательный `ТолькоПервыйЛист = Ложь` сохраняет старые вызовы с одним аргументом. При `Истина` читается первый лист в порядке книги, но ZIP уже проверен и распакован целиком. Массив `Листы` содержит описания всех листов: последующие остаются пустыми без отметки прочтения. Не принимайте их за прочитанные пустые листы. Аналогично чтение прерывается после ошибки листа.

## Пример серверного вызова

```bsl
Книга = мямXLSX.НоваяКнигаXLSX();
Лист = мямXLSX.ДобавитьЛистXLSX(Книга, "Данные");
мямXLSX.УстановитьЯчейкуXLSX(Лист, 1, 1, "Код");
мямXLSX.УстановитьЯчейкуXLSX(Лист, 2, 1, "001");
ДанныеКниги = мямXLSX.СформироватьXLSX(Книга);
Результат = мямXLSX.ПрочитатьКнигуXLSX(ДанныеКниги);
Если Не ПустаяСтрока(Результат.ОшибкаЧтения) Тогда
    ВызватьИсключение Результат.ОшибкаЧтения;
КонецЕсли;
Для Каждого ПрочитанныйЛист Из Результат.Листы Цикл
    Если Не ПустаяСтрока(ПрочитанныйЛист.ОшибкаЧтения) Тогда
        ВызватьИсключение ПрочитанныйЛист.ОшибкаЧтения;
    КонецЕсли;
КонецЦикла;
```

Книга и листы изменяются методами заполнения; `СформироватьXLSX` не меняет книгу и возвращает самостоятельные двоичные данные. Входные данные чтения остаются у вызывающего кода, результат — структуры/DOM в памяти. Срок их хранения определяет вызывающий код.

## Проверка в принимающей конфигурации

Методы выполняют обработку в памяти и не создают временных каталогов. Это свойство исходного кода, а не подтверждение работы всей конфигурации в безопасном режиме. После подключения проверьте компиляцию на своей версии платформы, чтение и запись поддерживаемых файлов, права/RLS, ограничения памяти и времени, а также используемые защиты. Исходные проверки и модели не заменяют такую приёмку. Не отключайте защиты ради этих модулей.

### XMLИзАрхива

Экспортный метод.

```bsl
Функция XMLИзАрхива(Архив, ИмяЧасти, КаталогЧтения) Экспорт
```

Читает UTF-8 XML из проверенного архива в памяти. Отсутствующая
  часть, DTD или ошибка XML вызывает исключение; архив не закрывает.

Параметры:
 Архив - Структура - результат мямZIP.Прочитать; архив, проверенный ЧастиКнигиXLSX.
 ИмяЧасти - Строка - разрешённое имя ZIP-части, не путь файловой системы.
 КаталогЧтения - Строка - сохранённый параметр совместимости, не используется.

Возвращаемое значение:
 ДокументDOM - разобранный документ части.

### ВнутренняяЧасть

Внутренний помощник.

```bsl
Функция ВнутренняяЧасть(Архив, Источник, Связь)
```

Разрешает цель внутренней связи и проверяет наличие части. Внешний/неизвестный режим и отсутствие части
  вызывают исключение.

Параметры:
 Архив - Структура - результат мямZIP.Прочитать; проверенный архив.

 Строка - имя существующей ZIP-части.

### ДатаExcel

Внутренний помощник.

```bsl

```

Переводит целую часть серийной даты в календарную строку. Неверные значения и фиктивный день 1900-02-29

Параметры:

Возвращаемое значение:
 Строка - dd.MM.yyyy либо пустая строка при отказе.

### ДополнитьГеометриюОбъединений

Внутренний помощник.

```bsl

```

Дополняет уже существующие ячейки границами объединений. Не создаёт виртуальные ячейки и не копирует значения между ними.

### ПроверитьАрхив

### ПрочитатьКнигуXLSX

Экспортный метод.

```bsl
Функция ПрочитатьКнигуXLSX(ДанныеФайла, ТолькоПервыйЛист = Ложь) Экспорт
```

Читает Transitional XLSX из двоичных данных без вычисления формул. Пределы: ZIP до 16 МиБ,
1–20 листов, номера строк до 20000, до 1000 ZIP-записей и 64 МиБ суммарно без сжатия.
Бинарный XLS, XLSM, шифрование и полный OOXML не поддерживаются. Входные данные не изменяет.

Параметры:
 ДанныеФайла - ДвоичныеДанные - полный ZIP книги, не путь и не адрес временного хранилища.
 ТолькоПервыйЛист - Булево - дополнение Trade: остановиться после первого листа в порядке книги.

Возвращаемое значение:
 Структура:
  * Листы - Массив из Структура - в порядке книги, с полями:
    * Имя - Строка - имя листа.
    * Строки - Массив из Структура - см. ПрочитатьМатрицу; числовые значения остаются текстом.
    * ОшибкаЧтения - Строка - ошибка этого листа либо пустая строка.
  * ОшибкаЧтения - Строка - ошибка подготовки книги либо пустая строка.
  * ПредупрежденияОчистки - Массив из Строка - сохранённое поле совместимости; в памяти всегда пустой массив.
Проверять ошибку книги и листов. После первой ошибки листа чтение прерывается: предыдущие данные
сохраняются, последующие заранее созданные листы остаются пустыми без отметки прочтения.
Внешних ресурсов транспорта нет; предупреждения очистки не формируются.

### ПрочитатьМатрицу

Внутренний помощник.

```bsl
Функция ПрочитатьМатрицу(ЛистXML, ОбщиеСтроки, СтилиДат, Даты1904)
```

Декодирует присутствующие строки XML-листа, не вычисляя формулы и не преобразуя числовой текст в число.
Неверное имя или пространство имён корневого элемента вызывает исключение; без sheetData возвращает
пустой массив. Проверки адреса, порядка строк и индекса общей строки могут вызвать исключение;
частичный массив тогда не возвращается. Некорректная серийная дата даёт пустую СохраненнаяДата.
Входные значения не изменяет.

Параметры:
 ЛистXML - ДокументDOM - worksheet в пространстве имён Transitional OOXML; строки по возрастанию до 20000.
 ОбщиеСтроки - Массив из Строка - таблица sharedStrings для ячеек типа s.
 СтилиДат - Соответствие - строковый индекс стиля → Истина для распознанного формата даты.
 Даты1904 - Булево - система дат workbook: Истина для 1904, Ложь для 1900.

Возвращаемое значение:
 Массив из Структура - только присутствующие строки в порядке XML:
  * Номер - Число - исходный номер строки.
  * Ячейки - Соответствие - буквы колонки → Структура ячейки:
    * Текст - Строка - исходное v, общая строка либо текст inlineStr; серийная дата и экспонента остаются текстом.
    * НетКэша - Булево - есть формула без непустого v.
    * ОшибкаExcel - Булево - тип ячейки e.
    * Адрес - Строка - исходный адрес ячейки.
    * Формула - Булево - есть элемент f; формула не вычисляется.
    * СохраненнаяДата - Строка - dd.MM.yyyy либо пусто; используется существующая ДатаExcel.
    * Числовая - Булево - тип отсутствует либо n; это признак, а не результат разбора числа.
