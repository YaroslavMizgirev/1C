### ЗаписатьПровестиДокумент

```bsl

```

Процедура выполняет запись/проведение/отмену проведения документа.

Параметры:
 ТекущийОбъект - ДокументОбъект,СправочникОбъект.
  Переданный объект записывается в выбранном режиме; при попытке записи могут выполняться обработчики объекта, даже если запись завершится ошибкой.
 РежимЗаписи - РежимЗаписиДокумента.
 Заголовок - Строка, Булево - (По умолчанию = "").
 РежимСообщений - Строка - "Нет","Все","Ошибки" Булево (По умолчанию = "Все").
 ЗаписыватьПередПроведением - Булево - По умолчанию = Истина.
 ПроверятьЗаполнение - Булево - По умолчанию = Истина.

Возвращаемое значение:
  Булево - действие выполнено.


### ИзменитьПометкуНаУдалениеУОбъекта

Экспортный метод.

```bsl
Функция ИзменитьПометкуНаУдалениеУОбъекта(ТекущийОбъект,ПометкаНаУдаление,Заголовок="",РежимСообщений="Все",СтруктураПараметров=Неопределено) Экспорт
```

Процедура выполняет изменение пометки на удаление у объекта.

Параметры:
 ТекущийОбъект - Ссылка, Объект.
  При отличающейся пометке вызывает УстановитьПометкуУдаления: меняет запись в базе. Если СтруктураПараметров содержит ОбъектПолучен, использует сам переданный объект, иначе получает объект по ссылке.
 ПометкаНаУдаление - Булево - Варианты значений: Истина - пометить на удаление, Ложь - снять пометку на удаление.
 Заголовок - Строка.
 РежимСообщений - Строка - Варианты значений: "Нет", "Все", "Ошибки".
 СтруктураПараметров - Структура:
  * ОбъектПолучен - Булево - При передачи объекта необходимо в параметр "СтруктураПараметров" добавить ключ "ОбъектПолучен".

Возвращаемое значение:
  Булево.

### СписокЗаполняемыхРеквизитов

Экспортный метод.

```bsl
Функция СписокЗаполняемыхРеквизитов(ПолноеИмяОбъектаМетаданных) Экспорт
```

Возвращает конечные реквизиты поддерживаемого объекта и его табличных частей. Служебные реквизиты исключает; табличные части как отдельные цели не возвращает. При неверном имени, неизвестном объекте или неподдерживаемом семействе возвращает пустой список.

Параметры:
 ПолноеИмяОбъектаМетаданных - Строка - полное имя вида Справочник.Имя; входную переменную не меняет.

 СписокЗначений - значение: полный путь реквизита; представление: название реквизита с контекстом табличной части. Отсортирован по представлению.

### СписокОбъектовМетаданныхПоИдентификаторам

Экспортный метод.

```bsl
Функция СписокОбъектовМетаданныхПоИдентификаторам() Экспорт
```

Читает зарегистрированные объекты конфигурации и расширений из справочников идентификаторов БСП. Пропускает помеченные на удаление идентификаторы, недоступные или устаревшие объекты и объекты без заполняемых реквизитов. Запрос к справочникам выполняется с правами текущего пользователя. Код МЯМ не включает привилегированный режим. Штатный метод БСП временно включает его при обращении к кэшу идентификаторов. Отказ запроса передаёт вызывающему коду.

Возвращаемое значение:
 СписокЗначений - значение: полное имя объекта; представление: источник (конфигурация/расширение), имя и синоним. Отсортирован по представлению; пустой, если подходящих объектов нет.

Для СписокОбъектовМетаданныхПоИдентификаторам обязательны справочники БСП `ИдентификаторыОбъектовМетаданных` и `ИдентификаторыОбъектовРасширений`, их актуальное штатное заполнение и экспортный метод `ОбщегоНазначения.ОбъектМетаданныхПоИдентификатору(Идентификатор, ВызыватьИсключение = Истина)`. Запрос к справочникам выполняется с правами текущего пользователя. Код МЯМ не включает привилегированный режим. Штатный метод БСП временно включает его при обращении к кэшу идентификаторов.
