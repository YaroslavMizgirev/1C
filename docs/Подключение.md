# Подключение библиотеки 1С

[← К оглавлению библиотеки](../README.md)

## Подключение

1. Создайте общие модули с точными именами файлов из `modules`. Скопируйте BSL.
2. Установите свойства из карточки каждого модуля. Global и Privileged остаются false; не включайте привилегированный режим.
3. Подключите все указанные библиотечные зависимости и БСП 3.1.12.323 для методов, использующих её API. Серверные вызовы из КлиентСервер сохранены в исходных ветках препроцессора; ВызовСервера требует ServerCall=true.
4. В вашем проекте отдельно выполните проверку модулей и сценариев; в этой поставке 1С и база не запускались.

## Контракты и границы

- В первом коммите поставлены 209 методов без согласованной доработки; второй добавляет 25 исправленных методов. 8 зависимых и 46 проектных методов не включены.
- Полный читатель XLSX (`ПрочитатьКнигуXLSX`, `ПрочитатьМатрицу`) отложен. В комплекте есть запись XLSX и низкоуровневые части формата. Не вызывайте отсутствующую точку чтения. При будущем подключении читателя правило экспоненты для числовой ячейки (−30…30) останется у читателя, не в общем разборщике.
- `УбратьПовторяющиесяПробелы` сворачивает только обычные пробелы, включая края; не обрезает их полностью.
- `ЭтоСсылка` в новом комплекте отсутствует. Для Тип используйте `ОбщегоНазначения.ЭтоСсылка`; составное ОписаниеТипов проверяйте по входящим типам.
- Методы чтения реквизитов передают в БСП `ВыбратьРазрешенные=Ложь`, `КодЯзыка=Неопределено`, если не задано иное. Применимость отборов и прав определяет вызывающий код.
- Потребители этой поставкой не изменяются. Перенос вызовов, настройка форм, миграции данных и публикация — отдельные действия.

### Числа и цифры

Разбор не использует региональное преобразование строк в число. Без явного формата точка или запятая — десятичный разделитель: `1,234` = `1.234`. Пробельные группы проверяются до очистки, включая U+00A0/U+202F: `1 234,56` допустимо, `12 34,56` вызывает исключение. Для `1,234.56` укажите `Точка`, для `1.234,56` — `Запятая`. Поддерживаются ведущие +/− и бухгалтерские скобки; внутренние знаки, экспонента, пустота и неверный ввод вызывают исключение. Точность — не более 38 разрядов и 38 дробных позиций; выход за границы и потеря точности вызывают исключение. Нулевой результат не означает ошибку. `ЭтоЦифры` принимает одну непустую строку без очистки и разрешённых исключений; `ЭтоЦифра` требует один символ.

Проверки заполнения явно сохраняют отказ: при ошибке `Отказ=Истина`, `СтандартнаяОбработка=Ложь`, независимо от исходных значений. Дополнительный список незаполненных полей в соответствующем методе сохранён.
