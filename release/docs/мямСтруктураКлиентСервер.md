Модули подключаются комплектом по зависимостям. Цикл между обработкой значений и общими описаниями типов не требует порядка создания: сначала создайте все модули, затем вставьте код и проверьте конфигурацию.

## Методы

### ЕслиСтруктураНеопределеноТоНовая

Экспортный метод.

```bsl
Процедура ЕслиСтруктураНеопределеноТоНовая(ПроверяемаяСтруктура) Экспорт
```

Проверяет значение структуры.
 Если значение "Неопределено", тогда значение заменяется на пустую структуру.

Параметры:
 ПроверяемаяСтруктура - Неопределено, Структура.
  Если передано Неопределено, заменяет переданную переменную новой пустой структурой; другое значение сохраняет.
