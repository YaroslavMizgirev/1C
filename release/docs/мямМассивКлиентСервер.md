## Методы

### ДобавитьВМассив

Экспортный метод.

```bsl
Функция ДобавитьВМассив(Значение1,Значение2=Неопределено,Значение3=Неопределено,Значение4=Неопределено,Значение5=Неопределено,Значение6=Неопределено,Значение7=Неопределено,Значение8=Неопределено,Значение9=Неопределено,Значение10=Неопределено,Знач МассивИсточник=Неопределено) Экспорт
```

Функция - Добавить в массив.
 Добавляет значения в массив-источник и возвращает его.

Параметры:
 Значение1 - Произвольное.
 Значение2 - Произвольное.
 Значение3 - Произвольное.
 Значение4 - Произвольное.
 Значение5 - Произвольное.
 Значение6 - Произвольное.
 Значение7 - Произвольное.
 Значение8 - Произвольное.
 Значение9 - Произвольное.
 Значение10 - Произвольное.
 МассивИсточник - Неопределено, Массив.
  Если Неопределено, переданная переменная заменяется новым массивом. Массив дополняется Значением1; добавление каждого из Значений2–10 зависит от условия Значение2 <> Неопределено.

Возвращаемое значение:
  - Массив Из Произвольное.


### ДополнитьМассив

Экспортный метод.

```bsl
Процедура ДополнитьМассив(МассивПриемник,МассивИсточник,ТолькоУникальныеЗначения=Ложь) Экспорт
```

Процедура - Дополнить массив.
 Дополняет массив МассивПриемник значениями из массива МассивИсточник.

Параметры:
 МассивПриемник       - Массив Из Произвольный - массив, в который необходимо добавить значения.
  Дополняет переданный массив значениями источника; при ТолькоУникальныеЗначения добавляет только отсутствующие значения.
 МассивИсточник       - Массив Из Произвольный - массив значений для заполнения.
 ТолькоУникальныеЗначения  - Булево - если Истина, то в массив будут включены только уникальные значения.
