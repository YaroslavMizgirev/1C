## Зависимости

Другие модули МЯМ не требуются.
БСП: прямых вызовов не обнаружено.
Сервисы платформы: стандартный глобальный контекст 1С.

Модули подключаются комплектом по зависимостям. Цикл между обработкой значений и общими описаниями типов не требует порядка создания: сначала создайте все модули, затем вставьте код и проверьте конфигурацию.

## Методы

### УдалитьКоманду

Экспортный метод.

```bsl
Процедура УдалитьКоманду(Форма,ИмяКоманды) Экспорт
```

Удаляет СОЗДАННУЮ ПРОГРАММНО команду формы.

Параметры:
 Форма    - ФормаКлиентскогоПриложения  - Форма клиентского приложения.
  Удаляет найденную команду из коллекции Команды переданной формы.
 ИмяКоманды - Строка            - Имя команды.


### УстановитьСвойстваЭлементу

Внутренний помощник.

```bsl
Процедура УстановитьСвойстваЭлементу(Элемент,СтруктураСвойств)
```

Устанавливает определенной команде формы заданные свойства.

Параметры:
 Элемент          - КомандаФормы.
  Меняет свойства переданного элемента по очереди из структуры; ошибка следующего свойства не отменяет уже присвоенные.
 СтруктураСвойств     - Структура - Ключ - имя свойства элемента формы, Значение - значение свойства элемента формы.
