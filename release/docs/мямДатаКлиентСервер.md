## Методы

### ЕслиДатаНеопределеноТоНовая

Экспортный метод.

```bsl
Процедура ЕслиДатаНеопределеноТоНовая(ТекущаяДата) Экспорт
```

Проверяет значение типа дата.
 Если значение "Неопределено", тогда значение заменяется на Дата(1,1,1).

Параметры:
 ТекущаяДата - Дата.
  Если передано Неопределено, заменяет переданную переменную Датой(1,1,1); другое значение сохраняет.
