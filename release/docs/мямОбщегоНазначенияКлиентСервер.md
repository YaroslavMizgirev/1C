| Свойство | Значение |
|---|---|
| Global | false |

## Зависимости

мямСтрокаКлиентСервер, мямМассивКлиентСервер, мямОбщегоНазначения, мямДатаКлиентСервер, мямБулевоКлиентСервер, мямЧислоКлиентСервер, мямОбщегоНазначенияВызовСервера
БСП: ОбщегоНазначенияКлиентСервер
Сервисы платформы: стандартный глобальный контекст 1С.

Модули подключаются комплектом по зависимостям. Цикл между обработкой значений и общими описаниями типов не требует порядка создания: сначала создайте все модули, затем вставьте код и проверьте конфигурацию.

### ЗаполнитьСписокРеквизитовТабличнойЧасти

Экспортный метод.

```bsl
Процедура ЗаполнитьСписокРеквизитовТабличнойЧасти(Форма,ТипМетаданных,ИмяОбъектаМетаданных,ИмяТабличнойЧасти,ИмяЭлемента) Экспорт
```

Дополняет список выбора элемента формы реквизитами выбранной табличной части, исключая служебные поля. При
  пустом имени табличной части ничего не делает.

Параметры:
 Форма - ФормаКлиентскогоПриложения - форма с изменяемым списком выбора.
  Дополняет СписокВыбора указанного элемента формы по мере обхода результата, без предварительной очистки. При пустом имени табличной части возвращается до изменений.
 ТипМетаданных - Строка - имя коллекции метаданных во множественном числе, например Справочники.
 ИмяОбъектаМетаданных - Строка - имя объекта в выбранной коллекции.
 ИмяТабличнойЧасти - Строка - имя табличной части объекта.
 ИмяЭлемента - Строка - имя элемента формы; его СписокВыбора дополняется без предварительной очистки.

### ПолучитьПараметрыДанныхВыбора

Экспортный метод.

```bsl
Функция ПолучитьПараметрыДанныхВыбора(СтрокаПоиска="",Отбор=Неопределено,ДополнительныеПараметры=Неопределено,ГруппыИЭлементы="Элементы") Экспорт
```

Функция - Получить параметры данных выбора.

Параметры:
 СтрокаПоиска - Строка - Текст введенный пользователем.
 Отбор - Структура - Где ключ - наименование параметра отбора и значение - значение параметра отбора. По умолчанию - Неопределено.
  Если Неопределено, переданная переменная заменяется новой пустой структурой до преобразования ГруппыИЭлементы; готовая структура не копируется.
 ГруппыИЭлементы - Строка - Принимаемые значения: "Группы", "ГруппыИЭлементы", "Элементы". По умолчанию - "Элементы".
  Переданная строковая переменная заменяется значением ИспользованиеГруппИЭлементов после инициализации двух структур; неверное имя вызывает ошибку платформы.
 ДополнительныеПараметры - Структура - Где ключ - наименование параметра дополнительного отбора и значение - значение параметра дополнительного отбора. По умолчанию - Неопределено.
  Если Неопределено, переданная переменная заменяется новой пустой структурой до преобразования ГруппыИЭлементы; готовая структура не копируется.

Возвращаемое значение:
  - Структура:
   * СтрокаПоиска - Строка.
   * Отбор - Структура.
   * ВыборГруппИЭлементов - ИспользованиеГруппИЭлементов.
   * ДополнительныеПараметры - Структура.
