# мямЧислоКлиентСервер

## Свойства общего модуля

| Свойство | Значение |
|---|---|
| Global | false |
| ClientManagedApplication | true |
| Server | true |
| ExternalConnection | true |
| ClientOrdinaryApplication | true |
| ServerCall | false |
| Privileged | false |
| ReturnValuesReuse | DontUse |

## Зависимости

Другие модули МЯМ не требуются.
БСП: прямых вызовов не обнаружено.
Сервисы платформы: стандартный глобальный контекст 1С.

Модули подключаются комплектом по зависимостям. Цикл между обработкой значений и общими описаниями типов не требует порядка создания: сначала создайте все модули, затем вставьте код и проверьте конфигурацию.

## Методы

### ОчиститьЗначениеЧисла

Экспортный метод.

```bsl
Процедура ОчиститьЗначениеЧисла(ЧислоЗначение) Экспорт
```

Процедура - Очистить значение числа.

Параметры:
 ЧислоЗначение - Число.
  Переданной переменной безусловно присваивается ноль.


### ЭтоЧисло

Экспортный метод.

```bsl
Функция ЭтоЧисло(ПроверяемоеЗначение) Экспорт
```

Функция - Это число.

Параметры:
 ПроверяемоеЗначение  - Произвольный.

Возвращаемое значение:
  - Булево.
