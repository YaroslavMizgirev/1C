## Методы

### СортироватьПоКлючу

Экспортный метод.

```bsl
Функция СортироватьПоКлючу(Знач ПроверяемоеСоответствие,СпособСортировки="Возр") Экспорт
```

Функция - Сортировать по ключу.

Параметры:
 ПроверяемоеСоответствие - Соответствие.
  Несмотря на Знач, очищает сам переданный объект соответствия и вставляет отсортированные ключи без прежних значений; возвращает этот же объект.
 СпособСортировки - Строка - Принимаемые значения: "Возр", "Убыв".

Возвращаемое значение:
  - Соответствие - Отсортированное по ключу.
