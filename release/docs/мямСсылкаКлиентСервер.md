## Зависимости

Другие модули МЯМ не требуются.
БСП: прямых вызовов не обнаружено.
Сервисы платформы: стандартный глобальный контекст 1С.

Модули подключаются комплектом по зависимостям. Цикл между обработкой значений и общими описаниями типов не требует порядка создания: сначала создайте все модули, затем вставьте код и проверьте конфигурацию.

## Методы

### ОчиститьЗначениеСсылочногоТипа

Экспортный метод.

```bsl
Процедура ОчиститьЗначениеСсылочногоТипа(СсылкаЗначение) Экспорт
```

Присваивает переданной переменной Неопределено, не изменяя запись информационной базы.

Параметры:
 СсылкаЗначение - Произвольный - изменяемая переменная, после вызова Неопределено.
  Переданной переменной безусловно присваивается Неопределено.
