## Методы

### ВыполненыНеобходимыеУсловияЗаполненияПолейОбъекта

Экспортный метод.

```bsl
Функция ВыполненыНеобходимыеУсловияЗаполненияПолейОбъекта(Форма,УсловияЗаполнения,СтандартнаяОбработка=Истина,Отказ=Ложь,СообщатьОбОшибках=Истина) Экспорт
```

При ошибках устанавливает Отказ = Истина и СтандартнаяОбработка = Ложь.
Функция - Выполнены необходимые условия заполненения полей объекта.

Параметры:
 Форма - ФормаКлиентскогоПриложения.
 УсловияЗаполнения - Строка - строка с условиями заполнения: ИмяРеквизита1>ИмяРеквизита2, ИмяРеквизита3<ИмяРеквизита2,
                              ИмяРеквизита2>=ИмяРеквизита4, ИмяРеквизита1<=ИмяРеквизита3, ИмяРеквизита4=ИмяРеквизита3,
                              ИмяРеквизита5<>ИмяРеквизита6 разделенные символом ",". Сравниваемые поля должны быть одного типа.
  Переданная переменная сначала заменяется строкой без пробелов, затем массивом условий через СтрРазделить; это выполняется до проверки и сохраняется при успехе и при последующей ошибке.
 СтандартнаяОбработка - Булево.
  При найденных ошибках переданной переменной присваивается Ложь; при успехе сохраняет входное значение.
 Отказ - Булево.
  При найденных ошибках переданной переменной присваивается Истина; при успехе сохраняет входное значение.
 СообщатьОбОшибках - Булево.

Возвращаемое значение:
  - Булево - Истина - все необходимые поля заполнены, Ложь - не все необходимые поля заполнены.
