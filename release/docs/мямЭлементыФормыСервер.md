## Зависимости

Другие модули МЯМ не требуются.
БСП: прямых вызовов не обнаружено.
Сервисы платформы: стандартный глобальный контекст 1С.

Модули подключаются комплектом по зависимостям. Цикл между обработкой значений и общими описаниями типов не требует порядка создания: сначала создайте все модули, затем вставьте код и проверьте конфигурацию.

## Методы

### ОпределитьЭлементФормы

Внутренний помощник.

```bsl
Процедура ОпределитьЭлементФормы(Форма,Элемент)
```

Процедура - Определить элемент формы.

Параметры:
 Форма   - ФормаКлиентскогоПриложения - Форма клиентского приложения.
 Элемент  - Строка, Элементы - достаточно указать имя элемента формы или передать элемент формы.
  Строковая переменная сначала заменяется коллекцией элементов, затем найденными объектами пути. При ошибке остаётся последний найденный объект; Неопределено и готовый элемент не меняются.


### ПолучитьСостояниеГруппировкиЭлемента

Внутренний помощник.

```bsl
Процедура ПолучитьСостояниеГруппировкиЭлемента(Элемент,Состояние)
```

Процедура - Получить состояние группировки элемента.

Параметры:
 Элемент   - ЭлементФормы.
  Меняет свойство Группировка переданного элемента только для явно обработанных кодов; при остальных кодах сохраняет прежнее значение.
 Состояние  - Число.

### УдалитьЭлемент

Экспортный метод.

```bsl
Процедура УдалитьЭлемент(Форма,ИмяЭлемента) Экспорт
```

Удалить РАНЕЕ СОЗДАННЫЙ ПРОГРАММНО элемент.

Параметры:
 Форма - ФормаКлиентскогоПриложения - изменяемая форма; ошибки изменения передаются вызывающему коду.
  Удаляет указанный элемент через УдалитьЭлементы, если элемент существует.
 ИмяЭлемента - Строка - Имя элемента.


### УдалитьЭлементы

Экспортный метод.

```bsl
Процедура УдалитьЭлементы(Форма,УдаляемыеЭлементы) Экспорт
```

Удалить РАНЕЕ СОЗДАННЫЕ ПРОГРАММНО элементы.

Параметры:
 Форма - ФормаКлиентскогоПриложения - изменяемая форма; ошибки изменения передаются вызывающему коду.
  Удаляет существующие элементы формы по мере обхода переданного списка; отсутствующие пропускает.
 УдаляемыеЭлементы - Массив Из Строка - Содержит строковые типы с именами удаляемых элементов.


### УстановитьСвойстваЭлементу

Внутренний помощник.

```bsl
Процедура УстановитьСвойстваЭлементу(Элемент,СтруктураСвойств)
```

Устанавливает элементу формы заданные свойства.

Параметры:
 Элемент          - КомандаФормы.
  Меняет свойства переданного элемента по очереди из структуры; ошибка следующего свойства не отменяет уже присвоенные.
 СтруктураСвойств     - Структура - Ключ - имя свойства элемента формы, Значение - значение свойства элемента формы.


### УстановитьСобытияЭлементу

Экспортный метод.

```bsl
Процедура УстановитьСобытияЭлементу(Элемент,СтруктураСобытий) Экспорт
```

Установливает элементу формы заданные события.

Параметры:
 Элемент      - Элементы.
  Меняет обработчики событий переданного элемента по очереди; ошибка следующего события не отменяет уже установленные.
 СтруктураСобытий - Структура - ключ - название события, значение - название процедуры/функции.
